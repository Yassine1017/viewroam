# ViewRoam

**Chase the view.**

ViewRoam is a mobile-first photography travel guide. Its Shot Guide experience
helps travelers reach an approximate shooting area, face the recommended
direction, and understand the framing, timing, and respectful-visit guidance
before taking a photograph.

## Local development

```bash
npm install
npm run dev
```

The Tokyo pilot includes five remotely researched Shot Guides: Tokyo Tower from
Zojo-ji, Kaminarimon, Shibuya Crossing, Tokyo Skytree from Sumida Park, and
Rainbow Bridge from Odaiba. Every shooting position, walking route, bearing,
rule, and sightline remains approximate and requires an on-site field check.

The prototype uses local JSON data, Leaflet, licensed local photo assets, and
LocalStorage. It does not use authentication, a hosted database, real camera
access, AI analysis, or augmented reality.
